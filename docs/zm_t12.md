# ZM T-12 コントローラ解析メモ

COWBOX Android Controller T-12 の BLE HID 仕様。実機確認済み（Phase 2〜3, Phase 6）。

---

## デバイス情報

| 項目                   | 値                  |
| ---------------------- | ------------------- |
| BLE アドバタイジング名 | `ZM T-12`           |
| MAC アドレス           | `03:12:08:20:34:12` |
| アドレスタイプ         | `0`                 |
| RSSI（実測）           | `-48 dBm`           |

**ペアリングモード**: X ボタン + HOME ボタン 長押し

---

## HID レポート構造

HOGP（HID over GATT Profile）で Input Report を Notify 送信。

```text
Byte 0 : LX axis  (0〜255, 中立=128)
Byte 1 : LY axis  (0〜255, 中立=128)
Byte 2 : RX axis  (0〜255, 中立=128)  ※ 未使用
Byte 3 : RY axis  (0〜255, 中立=128)
Byte 4 : D-pad    (未操作=0xFF, 各方向で対応ビットが 0 になる反転論理)  ※ 未使用
Byte 5 : ボタン下位
            bit1(0x02) = B  ← 全サーボリセット
            bit6(0x40) = L  ← Hand 左回転
            bit7(0x80) = R  ← Hand 右回転
Byte 6 : ボタン上位  ※ 未使用
```

## スティック値の特性

### 値の範囲

Phase 3 実測でフルレンジ（0〜255）に到達することを確認。

| 操作       | 実測値 |
| ---------- | ------ |
| 左/上 最大 | 0      |
| 右/下 最大 | 255    |
| 中立       | 128    |

### 正規化

```python
normalized = (raw - 128) / 128.0  # -1.0〜+0.992
```

## HID Notify レート

Phase 6 実測（`tools/hid_debug.py` 計測モード）。

| 操作状態                            | Notify | 平均間隔 | レート   |
| ----------------------------------- | ------ | -------- | -------- |
| 何も触れない（アイドル）            | なし   | -        | 0 Hz     |
| スティック倒し続け / ボタン押し続け | あり   | 約 32ms  | 約 31 Hz |
| スティックを動かし続け              | あり   | 約 31ms  | 約 32 Hz |

**特性**: イベント駆動型。入力がある間だけ約 30Hz で送信し、入力がなくなると停止する。
